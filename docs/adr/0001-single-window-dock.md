# 贴边用单窗口变形实现

悬浮球和预览都由同一个窗口改尺寸、改位置来实现，不另建一个悬浮球窗口。这样任务数据和计时器始终在同一个页面里，任务数、加急、到点闪动这些状态不用在两个窗口之间同步。窗口也一直可见，计时器不会因为窗口被隐藏而被系统挂起。

## Considered Options

- 双窗口：另建一个只放悬浮球的小窗口，贴边时把普通窗口藏起来。切换只是显示和隐藏，没有缩放问题；代价是状态要跨窗口同步，而且窗口藏起来后里面的计时器可能被系统挂起。

## Consequences

尺寸和位置要分两次设置，缩放时可能露出一帧中间状态；macOS 上缩放后可能留下旧的窗口阴影（tauri#4243）。如果原型里这两个问题明显，就改用双窗口，并把本条标为 superseded。
